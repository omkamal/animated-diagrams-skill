animated-svg — 12 style presets

Each card is a live GSAP loop in that style. Use a style with new_project.sh <slug> --theme <name> (add --transparent for a transparent canvas, --width/--height for any aspect — portrait shown below). Full specs: references/style-presets.md.

Camera patterns — large flows

For diagrams bigger than the canvas (long control flows, sequence diagrams, code walkthroughs, pipelines) the camera tells the story. Six variations, all built on the template's inline camera rig (camFit / camFitAll / camPanTo / camFollow / camHome). Specs: references/camera-large-flows.md.
